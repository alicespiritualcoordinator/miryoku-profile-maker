# 魅力楽々プロフィールメーカー Ver.0.1

Instagramを仕事に活用したい方が、7つの質問を通じて自分の魅力を整理できる、日本語のWebアプリです。白と淡いピンク、グリーンを使い、スマートフォンでも読みやすく、押しやすい画面にしています。

## できること

1. 7つの質問に1問ずつ回答し、Instagramで使用する名前を入力
2. ターゲット・提供内容・未来・強みを整理
3. Instagramの名前欄3案、自己紹介文3案、キャッチコピーを生成
4. 各案をコピー、回答を修正、最初からやり直す

前後の画面へ移動しても回答を保持します。やり直しの際は確認が表示されます。回答はメモリ内のみで保持し、再読み込み・画面を閉じると消えます。残したい結果はコピーして保存してください。

外部API、有料サービス、登録、ログイン、データベースは使用しません。回答や結果を外部へ送信しません。

## ブラウザだけで無料公開（GitHub Pages）

公開リポジトリならGitHub FreeのGitHub Pagesを利用できます。非公開リポジトリの場合、利用できるかはGitHubの契約プランによります。公開設定に変えるとソースコードも公開されるので、公開してよい内容かを確認してください。

1. このアプリと `.github/workflows/deploy-pages.yml` がGitHubの `main` に入っていることを確認します。別ブランチの場合はPull requestを作成してマージします。
2. リポジトリ上部の **Settings** をクリックします。
3. 左側の **Pages** をクリックします。
4. **Build and deployment** の **Source** で **GitHub Actions** を選びます。
5. リポジトリ上部の **Actions** をクリックします。
6. 左側の **Publish GitHub Pages** をクリックします。
7. **Run workflow** をクリックし、ブランチを **main** にして緑色の **Run workflow** をクリックします。
8. 数分待ち、実行結果に緑のチェックが付くことを確認します。
9. **Settings → Pages → Visit site** をクリックすると、ブラウザで実際に操作できます。

通常の公開先は https://alicespiritualcoordinator.github.io/miryoku-profile-maker/ です。初回デプロイ成功前は表示されません。GitHubが表示する **Visit site** のURLを優先してください。管理者権限がない場合はリポジトリ管理者にPages設定を依頼してください。

公開後はURLを知っている方がアプリを使えます。回答はそれぞれのブラウザ内だけで処理し、GitHubへ送信しません。GitHub Pagesはサイト配信時のアクセス情報を扱うサービスです。公開後もアプリ変更を `main` に反映すると自動で再公開されます。

## 起動方法

Node.js **20.19以上、または22.12以上**が必要です（この環境では24.19で確認）。初回はリポジトリのフォルダー内で実行します。

```sh
npm ci
npm run dev
```

ターミナルに表示されたアドレスを、自分のパソコンのブラウザで開いてください。終了は `Ctrl+C` です。

クラウド環境でnpmのキャッシュ先に書き込めない場合は、次を使ってください。

```sh
npm ci --cache /tmp/miryoku-npm-cache
```

## ビルドと確認

```sh
npm test
npm run build
npm run preview
```

`npm test` は文章生成のテスト3件を実行します。`npm run build` の成果物は `dist/` に出力します。`npm run preview` で成果物を確認できます。本番公開は別途、静的サイトのホスティング先に `dist/` を配置してください。

ブラウザでの手動確認：空欄のエラー表示 → 7問に回答 → 戻って回答保持を確認 → 名前を入力 → 結果7候補を確認 → コピーして貼り付け → 回答修正 → やり直しの確認と消去。スマートフォンとPC両方で確認してください。

## ファイル構成

- `index.html`：ページの土台
- `src/main.js`：質問、名前入力、結果画面と操作
- `src/generate.js`：回答から文章を作るルール
- `src/style.css`：スマートフォン対応のデザイン
- `tests/generate.test.js`：生成内容・文字数・入力検証のテスト
- `package.json` / `package-lock.json`：コマンドと依存関係
- `vite.config.js`：GitHub Pagesでの静的ファイルの読み込み設定
- `.github/workflows/deploy-pages.yml`：テスト・ビルド・無料公開の自動処理
- `.gitignore`：依存関係とビルド成果物をGit管理から除外

## 試作版の制約

ルールベースで回答を組み合わせるため、回答によっては言い回しの調整が必要です。名前欄は30文字以内、自己紹介文は150文字以内に短く整え、長い部分は「…」で省略します。回答にない実績・資格・数字は追加しません。公開前に省略部分と内容を確認してください。DMなどの案内もご自身の運用に合わせて変更してください。Instagramへの自動投稿はしません。

コピーはブラウザの権限やHTTPSの有無によって使えない場合があります。その場合は表示される案内に従い、文章を選択してコピーしてください。
